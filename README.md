# Помогатор

Бесплатный оверлей для собеседований и созвонов: распознавание речи, ответы
модели, скриншоты задач, запись встреч с выжимкой, тренажёр и тесты.

Приложение работает на ваших настройках: свой адрес API, ключ и модель либо
локальное распознавание. Регистрации, аккаунта, облака и платных минут нет.

## Возможности

- оверлей с подсказками, который не попадает в скриншоты и демонстрацию экрана;
- распознавание речи: свой API (OpenAI-совместимый или Cloudflare) или локально;
- ответы модели потоком, история ответов, копирование;
- задача и код-ревью по скриншоту — на любом мониторе;
- запись встреч с расшифровкой и выжимкой;
- тренажёр собеседования и 7 банков вопросов по 100.

## Структура

```
src/                 приложение Electron
  main.js            главный процесс, окна, IPC
  hotkeys.js         горячие клавиши
  wheel-hook.js      глобальный хук колеса
  screenshot.js      выделение области и vision-запросы
  meeting-store.js   сохранение и выжимка встреч
  prompt.js          сборка сообщений для модели
  config.js          ссылки на донаты и обратную связь
  renderer/          окна: оверлей, настройки, встреча, тренажёр, тесты

scripts/release.js   сборка и публикация версии
```

## Быстрый старт

```powershell
npm install
npm run dev
```

## Сборка

```powershell
npm run build
```

Артефакт: `dist/Pomogator-<версия>.exe`.

Релиз с повышением версии, копией на рабочий стол и тегом:

```powershell
npm run release minor
```

## Безопасность

- ключи провайдеров на клиенте шифруются через DPAPI;
- настройки и ключи не хранятся в репозитории;
- приложение не отправляет данные никуда, кроме выбранного вами API.
