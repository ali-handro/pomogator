# Changelog

Все заметные изменения проекта. Версии — по semver: `major.minor.patch`.

## 0.32.0 — 2026-11-10

### Настройка автообновления
- В «О программе» появилась галочка «Скачивать обновления автоматически при запуске».

## 0.20.0 — 2026-11-02

### Безопасность
- `TEST_LOGIN_CODE` в production больше не работает: сервер не стартует.
- `AUTH_SECRET` короче 32 символов в production — сервер не стартует.
- Ключи Cloudflare и OpenCode в `settings.json` шифруются через DPAPI
  (`keysEnc`); открытый текст удаляется при первом запуске.
- `/ai/chat` требует положительный баланс или пробные минуты и ограничен
  40 запросами в минуту — облако больше нельзя жечь бесплатно.
- Режим и ставка берутся из серверной сессии `/session/start`. Клиент больше
  не может прислать `kind: meeting` на собеседовании и платить меньше.
- IP за прокси берётся из последнего `X-Forwarded-For`: подделка первого
  значения не обходит лимиты.
- Админка: CSP с nonce, запрет встраивания, `nosniff`, сравнение токена
  за постоянное время, блокировка после 20 ошибок.
- Окна приложения запрещают навигацию на сторонние адреса.
- Лимит тела запроса для скриншотов поднят до 4 МБ — live coding и код-ревью
  через облако снова работают.
