# Ключи активации

- Закрытый ключ: `tools/license-private.pem` — **в git не попадает и в сборку не входит**.
  Без него новые ключи выпустить нельзя, поэтому храните резервную копию отдельно.
- Открытый ключ встроен в приложение: `src/license.js`.

## Выпуск ключа

```powershell
node tools/make-license.js month      # 30 дней
node tools/make-license.js season     # 90 дней
node tools/make-license.js year       # 365 дней
node tools/make-license.js lifetime   # бессрочно
node tools/make-license.js season 45  # произвольный срок в днях
```

Скрипт печатает строку вида `POMG1.<...>.<...>` — её и отправляем покупателю.
В приложении: «Настройки → Тариф → Ключ активации → Активировать».

## Как это работает

Ключ — подписанный набор данных `{plan, exp, id}`. Приложение проверяет подпись
встроенным открытым ключом, поэтому сервер для активации не нужен и интернет
не требуется. Ключ можно передать в любом виде: текстом, файлом, в письме.

## Что ограничено бесплатно

`src/license.js` → `FREE_LIMITS`: 20 ответов и 5 скриншотов в день.
Встречи, тренажёр и тесты бесплатны всегда. Пробный период — 7 дней (`TRIAL_DAYS`).
